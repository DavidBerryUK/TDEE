# Stories

This directory contains the user stories for the TDEE project. Each story lives in its own folder
(`story-NNN-<slug>/`) with a `story.md` (the source of truth) and a `plan.md` (the implementation
plan); a few add further notes (e.g. `palettes.md`, `review-findings.md`, `changes-summary.md`,
`implementation-summary.md`).
